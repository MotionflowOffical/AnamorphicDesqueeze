# Third-party component

This project uses **ExifTool** by Phil Harvey as an external command-line dependency for DNG metadata reading/writing.

ExifTool is **not bundled in this ZIP**. On Windows, the app or `install_exiftool.ps1` can download the current official 64-bit Windows package directly from `https://exiftool.org/`.

See the ExifTool site for its current license, documentation, and releases.
